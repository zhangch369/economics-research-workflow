# 核心 AI 对话与恢复

此目录保存重要讨论的可移植记录。普通闲聊无需逐条抄写；涉及规格、样本、变换顺序、保留/删除决定、失败诊断、正式结果、写作定稿时，任务结束即留一张恢复卡。

```text
ai_records/
├── INDEX.csv
├── START_HERE.txt
├── templates/SESSION.md
└── YYYYMMDD_topic/
    ├── CHAT_CORE.md          关键原话与明确标注的摘要
    ├── RESTORE.md            当前版本、恢复命令、验收与下一步
    └── transcript.*          可选：从原客户端导出的完整对话
```

原生聊天 ID/链接用于追溯；本地核心记录用于跨客户端接手。不要只留一个可能失效的聊天链接。用户原话加引号，AI 摘要注明摘要；建议未获接受不得写成“用户已决定”。表格数值以可追溯输出为准。

每张恢复卡必须绑定：任务/聊天标识、相关规格、代码提交或快照、输入数据版本、运行目录、实际样本、表图、写作版本、已完成/未完成。缺项写“未记录”，不要补造。

该目录没有自动读取所有客户端历史的能力。支持导出的客户端可把对话存进 transcript；其他客户端保存关键原话和摘要即可。不要把密钥、完整个人信息或受限数据粘贴进对话存档。
